# Replication of Card & Krueger (1994): Minimum Wages and Employment

## 01 Project Overview
This project replicates the empirical analysis of Card & Krueger (1994), "Minimum Wages and Employment: A Case Study of the Fast-Food Industry in New Jersey and Pennsylvania." The study evaluates the employment impact of New Jersey's minimum wage increase from $4.25 to $5.05 per hour in April 1992, using a Difference-in-Differences (DiD) design with eastern Pennsylvania as the control group.

## 03 Data Sources
Raw Data: data/raw/public.csv is provided by the course (Package 01). It contains store-level survey data of 410 fast-food restaurants in New Jersey and eastern Pennsylvania from two survey waves (February-March 1992 and November-December 1992).

Processed Data: data/processed/cleaned_data.csv is generated by running code/00_clean_data.do. It includes some constructed variables.

## 04 How to Reproduce
Clone this repository to your local machine.

Ensure the raw data public.csv is placed in the data/raw/ folder.

Step 1 (Data Cleaning): Open Stata, set the working directory to the project root, and run code/00_clean_data.do. This will generate cleaned_data.csv in the data/processed/ folder.

Step 2 (Analysis): Open the Python scripts in the code/ folder and run them in sequence:

1.`01_descriptive.py`: Replicate Table 2.
2.`02_did_analysis.py`: Replicate Table 3 & Table 4.
3.`03_extension.py`: Run the independent extension analysis.

Step 3 (Outputs): All generated tables and figures will be automatically saved in the output/ folder.

## 05 Results Summary

Running the scripts sequentially will automatically generate the main tables and figures in the `output/` folder.
1. Table 2 & Figure 1: Successfully replicated the descriptive statistics and wage distributions. Minor discrepancies (e.g., Recruiting Bonus) are documented in `report.md`.
2. Table 3 & Table 4: The DiD regression results confirm no negative employment effect, consistent with the original paper.
3. Independent Extension: A price pass-through analysis was conducted, showing restaurants passed the minimum-wage cost to consumers via higher entree prices. Full details are in `report.md`.
