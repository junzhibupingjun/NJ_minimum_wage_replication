# Replication of Card & Krueger (1994): Minimum Wages and Employment

##01 Project Overview
This project replicates the empirical analysis of Card & Krueger (1994), "Minimum Wages and Employment: A Case Study of the Fast-Food Industry in New Jersey and Pennsylvania." The study evaluates the employment impact of New Jersey's minimum wage increase from $4.25 to $5.05 per hour in April 1992, using a Difference-in-Differences (DiD) design with eastern Pennsylvania as the control group.

##03 Data Sources
Raw Data: data/raw/public.csv is provided by the course (Package 01). It contains store-level survey data of 410 fast-food restaurants in New Jersey and eastern Pennsylvania from two survey waves (February-March 1992 and November-December 1992).

Processed Data: data/processed/cleaned_data.csv is generated by running code/00_clean_data.do. It includes constructed variables such as full-time equivalent (FTE) employment, the New Jersey dummy, and the wage gap (GAP) variable.

##03 How to Reproduce
Clone this repository to your local machine.

Ensure the raw data public.csv is placed in the data/raw/ folder.

Step 1 (Data Cleaning): Open Stata, set the working directory to the project root, and run code/00_clean_data.do. This will generate cleaned_data.csv in the data/processed/ folder.

Step 2 (Analysis): Open the Jupyter Notebooks in the `code/` folder and run the cells in sequence:

- `01_descriptive.py`: Replicate Table 2 (Descriptive Statistics).
- `02_did_analysis.ipynb`: Replicate Table 3 & Table 4 (DiD Regressions).
- `03_extension.ipynb`: Run the independent extension analysis.

Step 3 (Outputs): All generated tables and figures will be automatically saved in the output/ folder.
